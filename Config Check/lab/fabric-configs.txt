EVPN-VXLAN FABRIC: 2 SPINES + 2 LEAVES (lab EVPN_VXLAN_QFX)
==========================================================
Design: eBGP IPv4 underlay + eBGP EVPN overlay, unique ASN per device,
bridged only (no IRB). One VXLAN VNI: VLAN 100 / VNI 10100.
The old QinQ / SIPT service is removed: the leaf-to-leaf ge-0/0/3 link is
gone from the EVE lab, and the cleanup block below deletes its config.
The fabric uses ge-0/0/0 and ge-0/0/1 on every switch; VPCs are on leaf ge-0/0/2.

ADDRESSING
----------
Device   Mgmt (fxp0)       Loopback (lo0.0)   ASN
SPINE1   192.168.1.54/24   10.255.0.1/32      65001
SPINE2   192.168.1.55/24   10.255.0.2/32      65002
QFX1     192.168.1.52/24   10.255.0.11/32     65011   (Leaf_1)
QFX2     192.168.1.53/24   10.255.0.12/32     65012   (Leaf_2)

Fabric links (/31, MTU 9192)
Same port number at both ends of every link:
SPINE1 ge-0/0/0 10.0.1.0/31  <->  QFX1 ge-0/0/0 10.0.1.1/31
SPINE1 ge-0/0/1 10.0.1.2/31  <->  QFX2 ge-0/0/1 10.0.1.3/31
SPINE2 ge-0/0/0 10.0.2.2/31  <->  QFX2 ge-0/0/0 10.0.2.3/31
SPINE2 ge-0/0/1 10.0.2.0/31  <->  QFX1 ge-0/0/1 10.0.2.1/31

Hosts on VLAN 100 (VNI 10100)
VPC1 on QFX1 ge-0/0/2   ip 10.100.0.1/24
VPC2 on QFX2 ge-0/0/2   ip 10.100.0.2/24

ORDER OF WORK
-------------
1. In EVE: start Spine_1, wait until it boots (about 5-8 min), then Spine_2.
   Start them one at a time. Leaf_1 and Leaf_2 must be (re)started after the
   lab change so that their new fabric links come up.
2. On each spine's console, log in as root (no password on first boot), then:
       cli
       configure
       set system root-authentication plain-text-password   (prompts twice)
   then paste the spine block below and type: commit and-quit
3. On each leaf: configure, paste the QinQ cleanup block, then the leaf's
   fabric block, then: commit and-quit  (one commit for both).
4. Run the checks at the bottom.


############################################################################
### SPINE1 (Spine_1)
############################################################################
set system host-name SPINE1
set system services ssh root-login deny
set system services ssh protocol-version v2
set system services netconf ssh
set system login class cc-ro permissions view
set system login class cc-ro permissions view-configuration
set system login class cc-ro deny-commands "(request|clear|restart|start|file|configure)"
set system login user configcheck class cc-ro
set system login user configcheck authentication ssh-ed25519 "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIDDJDeudzYLqGY+XYbBiHEReRg3tXuNWETjZA8nbqb73 configcheck@config-check"
set interfaces fxp0 unit 0 family inet address 192.168.1.54/24
set interfaces lo0 unit 0 family inet address 10.255.0.1/32
set interfaces ge-0/0/0 description "to QFX1 ge-0/0/0"
set interfaces ge-0/0/0 mtu 9192
set interfaces ge-0/0/0 unit 0 family inet address 10.0.1.0/31
set interfaces ge-0/0/1 description "to QFX2 ge-0/0/1"
set interfaces ge-0/0/1 mtu 9192
set interfaces ge-0/0/1 unit 0 family inet address 10.0.1.2/31
set routing-options router-id 10.255.0.1
set routing-options autonomous-system 65001
set routing-options forwarding-table export ECMP
set policy-options policy-statement ECMP then load-balance per-packet
set policy-options policy-statement UNDERLAY-EXPORT term LO0 from interface lo0.0
set policy-options policy-statement UNDERLAY-EXPORT term LO0 then accept
set protocols bgp group UNDERLAY type external
set protocols bgp group UNDERLAY export UNDERLAY-EXPORT
set protocols bgp group UNDERLAY multipath multiple-as
set protocols bgp group UNDERLAY bfd-liveness-detection minimum-interval 1000
set protocols bgp group UNDERLAY bfd-liveness-detection multiplier 3
set protocols bgp group UNDERLAY neighbor 10.0.1.1 description QFX1
set protocols bgp group UNDERLAY neighbor 10.0.1.1 peer-as 65011
set protocols bgp group UNDERLAY neighbor 10.0.1.3 description QFX2
set protocols bgp group UNDERLAY neighbor 10.0.1.3 peer-as 65012
set protocols bgp group OVERLAY type external
set protocols bgp group OVERLAY multihop no-nexthop-change
set protocols bgp group OVERLAY local-address 10.255.0.1
set protocols bgp group OVERLAY family evpn signaling
set protocols bgp group OVERLAY keep all
set protocols bgp group OVERLAY multipath multiple-as
set protocols bgp group OVERLAY bfd-liveness-detection minimum-interval 3000
set protocols bgp group OVERLAY bfd-liveness-detection multiplier 3
set protocols bgp group OVERLAY neighbor 10.255.0.11 description QFX1
set protocols bgp group OVERLAY neighbor 10.255.0.11 peer-as 65011
set protocols bgp group OVERLAY neighbor 10.255.0.12 description QFX2
set protocols bgp group OVERLAY neighbor 10.255.0.12 peer-as 65012
set protocols lldp interface all
